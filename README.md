# Real Estate Sales Dashboard (Excel)

## 📊 Project Overview
An interactive Real Estate Sales Dashboard built in Microsoft Excel using Pivot Tables, Pivot Charts, Slicers, and KPI Cards.

## 🚀 Features
- Total Sales KPI
- Total Properties KPI
- Total Cities KPI
- Average Property Price KPI
- Sales by City
- Sales by Property Type
- Sales by Bedrooms
- Interactive Slicers

## 🛠️ Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
